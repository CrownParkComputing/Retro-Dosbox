- Simpler setup: install Windows 98 or FreeDOS in a three-screen wizard.
- Guided Launch: play a game from a disc, boot Windows or FreeDOS, or a DOS prompt.
- One folder for everything: games, discs and machines, set up on first run.
- Customizable on-screen controls: drag, resize and add buttons; 3dfx Voodoo for 3D.
- Media screen: CDs, floppies and hard disks; make or delete disks.
- Each game keeps its own dosbox.conf and folders.
