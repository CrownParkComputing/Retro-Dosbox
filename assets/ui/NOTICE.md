# Bundled interface assets

## ui-font.ttf — Liberation Sans Regular

SIL Open Font License 1.1. Liberation Sans is metric-compatible with Arial and
ships on essentially every Linux distribution; it is redistributable inside an
application, which is why it is here rather than a system font.

It is bundled rather than looked up on the host because there is no font this
app can rely on finding: Android has no Liberation, iOS has no fontconfig, and
a UI that silently falls back to a 1980s bitmap face on two platforms out of
three is not a design.

## wordmark.png

Ours. Generated by `tool/make_icons.py`, which builds it from the same three
pieces as the launcher icon — the Retro script, the machine name, and the
amber `C:\>` — so the two cannot drift into being different logos.
