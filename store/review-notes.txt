THIS BUILD IS A COMPLETE REWRITE

The app you last reviewed was built with Flutter. This one is not: the
interface is now native SDL3 with Dear ImGui, in the same process as the
emulator, and the Flutter application has been removed from the project
entirely. The binary, the interface and the code are new.

HOW TO SEE IT WORKING, WITH NOTHING TO SUPPLY

No account, login, credentials or files are needed. On a clean install:

  1. First run asks where DOS games should live. Tap Continue.
  2. The library already lists two entries, both bundled: "Retro-DOS demo"
     and "FreeDOS 1.3 (answer N for a DOS prompt)".
  3. Tap either. An emulated PC boots and runs it.

The earlier submission noted that the engine exited during start-up on the
Simulator, so a recording could not show a DOS program running. That is fixed
and no longer true -- it was a consequence of the old Flutter architecture,
where the engine sat behind a plugin boundary. It now runs on the Simulator and
on hardware alike.

ABOUT NETWORK ACCESS, AND WHAT THE SOURCE REPOSITORY SHOWS

The iOS build makes no network requests of any kind: no authentication,
payments, analytics, advertising, AI, or third-party data.

The repository referenced above also contains an Android-only feature called
RetroMedia, which signs in to a server for box art. We mention it so it is not
a surprise: it is excluded from this build at COMPILE time, not hidden behind a
setting or a permission. On anything that is not Android, media_available() and
media_downloads_available() return false and every entry point is an empty
stub, so the pages do not exist and no client is linked in.
